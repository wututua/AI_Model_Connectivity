# v1.0.0-beta.6

## 中文

本次 Beta 预发布增加原生模型协议、可筛选的监控历史和管理员操作审计，并修复用量与事件恢复中的问题。用于评估和升级验证，不是 RC 或正式稳定版。

### 新增

- **原生 Anthropic / Gemini**：显式选择 Messages 或 generateContent，支持文本、SSE 流式、系统提示词、输出上限、文本断言、网络诊断及上游用量。Gemini 思考内容不作为有效文本，思考 Token 计入输出。
- **分页模型发现**：自动遍历原生模型目录，每页计入每日请求预算；任一页失败时不提交部分清单。继续遵守发现确认阈值、模型批准和数量限制。
- **监控历史查询**：诊断与事件支持 Provider、模型、状态和时间范围筛选，以及服务端游标分页。诊断还可按能力和错误类型筛选，事件可区分模型检测与模型发现。
- **操作审计**：记录已验证操作者、白名单操作、HTTP 状态及结果，覆盖账号、配置、Provider、检测、通知、备份、指标凭据和更新请求。可筛选和分页，最多保留 90 天 / 10,000 条。

### 修复与保护

- Chat 上游返回负数 Token 时不再减少已统计消耗；缺失、不一致或汇总溢出的用量不作为完整费用证据。
- Embedding 不再覆盖公共用量校验结果；总量矛盾、负数或异常输出计数不会被误标为费用已知。
- 暂停或停用 Provider 不再被当作模型发现故障恢复的证据。
- 切换协议会取消旧的模型同步，避免迟到响应影响新配置。
- 原生请求沿用地址校验、禁止重定向、超时及响应大小限制；Gemini 密钥使用请求头，不写入 URL。
- 审计不保存请求正文、路径、查询、请求头、密码、会话、API Key 或原始错误；失败登录不保存提交的用户名。
- 新页面覆盖加载、失败、空结果、请求乱序、筛选重置及桌面 / 手机布局。

### 升级注意

1. 升级前停服，备份完整数据目录、旧程序和服务配置。启动时添加审计表与查询索引；回退应恢复匹配的程序和数据库备份。
2. 下载对应平台的完整压缩包，核对 `SHA256SUMS.txt`，保留配套 `web/`、文档与资源。
3. **Provider 类型不是协议选择器。** 原有 `type=anthropic` / `type=gemini` 继续走 OpenAI 兼容接口。使用原生接口须显式设置 `probe.protocol`，并确认 Base URL 包含对应版本路径。
4. Anthropic 预设省略温度；Gemini 预设省略温度并设置 1024 输出上限。切换协议不自动修改地址或密钥。预设不保证所有模型可用，也不保证固定费用。
5. 工具调用结构和 Embedding 探测仍仅支持非流式 OpenAI 兼容配置；不支持图像、音频或原生工具执行。
6. 审计只记录升级后的请求，不补录旧操作；HTTP 202 表示已受理，不等于异步检测或更新完成。自动后台行为继续查看任务、通知与监控记录。
7. 安装器和更新页选择 `preview`，或显式指定 `--version v1.0.0-beta.6`。此预发布不更新稳定版或 Docker `latest`。

### 验证与限制

- 发布门禁包含 Linux Go race、Windows Go 测试、`go vet`、依赖漏洞扫描、前端单元测试、构建、浏览器回归及隔离安装器测试。
- 增加真实 HTTP 集成测试和独立发布包升级验收脚本，覆盖旧账号 / 会话、配置、历史、用量、事件、备份及新功能。模拟上游不会产生付费调用。
- 费用仅估算完整已知用量。缓存、特殊工具计价或缺少最终流式用量时，保留有效 Token 但将费用标为未知；最终以供应商账单为准。
- 审计为尽力写入，与业务修改不在同一事务；进程中断、磁盘故障或数据库长时间占用可能造成记录缺失，不提供防篡改保证。
- 原生发现最多 100 页、10,000 个去重模型和 8 MiB；单个响应 / SSE 事件上限 1 MiB，完整流上限 8 MiB。
- 真实付费上游、长期调度、macOS 执行和 Linux/systemd 实机更新 / 回滚 / 断电恢复仍需目标环境验收。通过测试不等于没有任何缺陷。

详细说明：[原生协议](../native-protocols.md)、[监控中心](../monitoring-center.md)、[操作审计](../audit.md)。

## English

This Beta prerelease adds native model protocols, searchable monitoring history and administrator operation auditing, with fixes to usage accounting and incident recovery. It is intended for evaluation and upgrade validation, not as an RC or stable production release.

### Added

- **Native Anthropic / Gemini**: explicitly select Messages or generateContent, with text, SSE streaming, system prompts, output limits, text assertions, network diagnostics and upstream usage. Gemini thinking content is excluded from visible text while thinking tokens count toward output usage.
- **Paginated discovery**: native model catalogs are traversed automatically, reserving request budget for each page. Any failed page rejects the partial catalog. Discovery confirmation, model approval and model-count limits still apply.
- **Monitoring history**: filter diagnostics and incidents by provider, model, status and time range, with server-side cursor pagination. Diagnostics also support capability/error filters; incidents distinguish model checks from discovery failures.
- **Operation audit**: verified actor identity, allowlisted operations, HTTP status and outcomes for accounts, configuration, providers, checks, notifications, backups, metrics credentials and update requests. Searchable history retains up to 90 days / 10,000 records.

### Fixes And Safeguards

- Negative Chat usage no longer reduces recorded consumption. Missing, inconsistent or overflowing usage sums are not complete pricing evidence.
- Embedding checks no longer override shared usage validation. Inconsistent totals, negative counts or unexpected output counts are not marked as known costs.
- Paused or disabled providers no longer count as recovery evidence for discovery incidents.
- Changing protocols cancels earlier discovery requests, preventing late responses from changing the new draft.
- Native requests retain address validation, redirect rejection, timeouts and response-size limits. Gemini credentials use a header, never the URL.
- Audit records exclude request bodies, paths, queries, headers, passwords, sessions, API keys and raw errors. Failed login records do not retain submitted usernames.
- New views cover loading, errors, empty results, out-of-order requests, filter resets and desktop/mobile layouts.

### Upgrade Notes

1. Stop the service and back up the complete data directory, previous program and service configuration. Startup adds the audit table and query indexes. Rollback requires matching program and database backups.
2. Download the full archive for your platform, verify `SHA256SUMS.txt`, and retain the matching `web/`, documentation and assets.
3. **Provider type does not select the protocol.** Existing `type=anthropic` / `type=gemini` configurations continue using OpenAI-compatible APIs. Native APIs require explicit `probe.protocol` selection and the correct versioned Base URL.
4. Native presets omit temperature; the Gemini preset sets an output limit of 1024. Changing protocols does not automatically change addresses or credentials. Presets do not guarantee model compatibility or fixed costs.
5. Tool-call structure and embedding checks still require non-streaming OpenAI-compatible configuration. Image, audio and native tool execution are not supported.
6. Auditing begins with requests after upgrading and does not reconstruct earlier operations. HTTP 202 means accepted, not completed. Background activity remains in task, notification and monitoring records.
7. Select `preview` in the installer/update view or specify `--version v1.0.0-beta.6`. This prerelease does not update the stable release or Docker `latest`.

### Validation And Limits

- Release gates include Linux Go race tests, Windows Go tests, `go vet`, dependency vulnerability scans, frontend unit tests/build, browser regressions and isolated installer tests.
- New real-HTTP integration tests and an isolated release-upgrade acceptance script cover preserved accounts/sessions, configuration, history, usage, incidents, backups and new features. Mock upstreams make no paid calls.
- Cost estimates require complete known usage. Cache pricing, special tool pricing or missing final streaming usage retains valid token counts but marks cost unknown. Supplier invoices remain authoritative.
- Auditing is best-effort and not in the same transaction as business changes. Process interruption, disk failure or prolonged database contention can lose records; it is not tamper-proof.
- Native discovery is bounded to 100 pages, 10,000 unique models and 8 MiB. Individual responses/SSE events are limited to 1 MiB and complete streams to 8 MiB.
- Real paid upstreams, sustained scheduling, macOS execution and real Linux/systemd updates, rollback and power-loss recovery still require target-environment acceptance. Passing tests does not guarantee absence of defects.
