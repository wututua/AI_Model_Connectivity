## 下载与升级

- 在 [GitHub Releases](https://github.com/wututua/AI_Model_Connectivity/releases) 下载对应版本及平台的压缩包。
- 校验 `SHA256SUMS.txt`，完整保留发布包中的静态资源。
- 升级前备份数据库，并阅读该版本的升级注意事项。
- 预发布版本不等于稳定版；版本标签及已发布文件不应被后续修复覆盖。

未发布的文档和代码变化见[更新日志](../../CHANGELOG.md#未发布)。
